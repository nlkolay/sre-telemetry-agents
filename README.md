# SRE Automation & Telemetry Agents 🐍⚙️

Набор легковесных демонов на Bash и Python для сбора аппаратной телеметрии, автоматического реагирования на инциденты и управления жизненным циклом данных (Data Lifecycle Management).

## 🛠️ Инструменты

### 1. Data Retention Agent (DLM)
Асинхронный Python-демон для контроля свободного места и умной ротации данных.
* Взаимодействует с REST API медиасерверов (Jellyfin, Radarr, Sonarr).
* Включает **Fail-Safe логику**: валидирует наличие тегов (например, `collection`), проверяет статусы просмотра у *всех* пользователей перед отправкой `DELETE` запросов.
* Предотвращает переполнение файловой системы (`Out of Space`), защищая базы данных SQLite/Postgres от повреждения.

### 2. Proxmox MQTT Telemetry Agent
Bash-демон для трансляции аппаратных метрик в систему мониторинга (Home Assistant / Prometheus).
* Парсит вывод `smartctl` для мониторинга температуры HDD и состояния секторов (Pending Sectors).
* Отправляет телеметрию CPU/RAM и использует `MQTT Discovery` для авторегистрации датчиков.

### 3. Safe Disk Migration Script
Скрипт-обертка для `rsync`, написанный для безопасной миграции терабайтов данных между изношенными дисками.
* В цикле отслеживает температуру дисков. 
* При достижении критического порога температуры (или при появлении битых секторов в SMART) отправляет `SIGKILL` процессу rsync для предотвращения физического разрушения диска.
